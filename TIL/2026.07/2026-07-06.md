**2. Code Implementation (코드 구현)**

**Problem:** 행렬 외적 계산에 용이한 tilde 연산자를 coordinate_transformation.py의 Attitude class 안에서 정의했더니 Attitude.tilde_matrix와 같이 길게 적어야 하는 번거로움이 발생함. dcm을 quaternions로 변환하는 Sheppard's method에서 필연적으로 np.sqrt를 사용함. 이때 부동소수점의 한계로 b0가 음의 제곱근으로 나올 수 있고, 이는 자세 변화의 shortest path를 계산하는데 있어서 심각한 오류를 야기할 수 있음을 이해함.

**Resolution:** gnc_math.py라는 새로운 utils 파일을 만들어 그 안에 tilde_matrix와 inertia tensor를 principal inertias로 변환하는 함수를 정의함. np.sqrt(max(0, data))와 같이 sqrt 안에 들어갈 값의 최솟값을 0으로 제한함. 이로써 매우 0에 가까워 미세한 음수가 되는 현상을 막을 수 있었음.

**Insight:** dcm을 기준으로 하는 객체 기반 utils 파일 하나를 완성할 수 있었다. 향후 직접 작성한 Runge-Kutta 4th order numerical integrator를 기반으로 한 kinematics_differential_equations.py 파일도 작성할 예정이다.
