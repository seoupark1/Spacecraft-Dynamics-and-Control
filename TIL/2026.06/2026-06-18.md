**2. Code Implementation (코드 구현)**

**Problem:** 다른 rotation parameters와 달리, MRPs는 singularity를 피하기 위해 sigma의 norm이 1보다 작음을 지속적으로 확인해야 함. 이에 따라 integration 과정 중간에 개입할 수 없는 내장함수 ode45는 사용 불가능, numerical 
integrator를 직접 구현해야함.

**Resolution:** k1, k2, k3, k4에 가중치를 다르게 부여하는 Runge-Kutta의 기본적 원리를 이해함. 과거의 데이터로 다음 step의 값을 구하는 과정을 반복하는 형태로 코드를 만듦.

**Insight:** 정해진 dt 안에 process를 끝내야 하는 우주선의 on-board 컴퓨터에서 4/5th order를 사용하면 dt가 가변적임에 따라 타이밍이 맞지 않는 치명적 오류가 발생할 수 있음을 깨달음. 실제 우주선에서는 절대적으로 4th order 코드를 
직접 만들어 사용해야 한다.
