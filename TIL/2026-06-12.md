**Problem:** codespace에 octave를 설치하고 matlab과 동일한 ode45 함수를 불러오는 과정에서 error가 발생함.

**Resolution:** 전에 확장 프로그램으로 jupyter를 설치했을 때 백지 상태가 되었던 것과 마찬가지로, octave를 포함한 codespace 내의 모든 프로그램이 국방망에 의해 차단되어 있다는 사실을 깨달음. 결국 .py와 구조적으로 비슷한 형태의 파일에서 코드 적는 연습을 하기 위해, 코랩에서 하나의 셀에 모든 코드를 때려넣는 방식을 사용하기로 함. 

**Insight:** 사지방에서의 최적의 파일 생성 및 업로드 방식을 찾는 과정에서 F12 버튼으로 서버 차단을 확인하는 방법, 터미널의 역할과 명령법을 습득함. 국방망은 공부에 도움이 되지 않는다.


% clear; clc; close all;

% time, initial value 입력
tspan = [0, 42];
q0 = [0.4; 0.2; -0.1];

% 함수 실행
[t, q] = ode45(@crp_diff, tspan, q0);

% t=42s에서 norm 구하기
q_norm = norm(q(end, :));
disp(q_norm);

% crp differential kinematic equations 정의
function q_dot = crp_diff(t, q)
    % omega
    omega = [sin(0.1*t); 0.01; cos(0.1*t)] * 3 * (pi/180);

    % tilde 연산자는 행렬의 cross product를 가능하게 만든다
    q_tilde = [0, -q(3), q(2);
               q(3), 0, -q(1);
               -q(2), q(1), 0];

    q_dot = 1/2 * (eye(3) + q_tilde + q*transpose(q)) * omega;

end
